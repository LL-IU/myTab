    使用方法

    基本：点击字母格子进入对应网站；点击空格子即可编辑。

    编辑：右键任意格子，填写名称 / 网址 / 图标，Enter 保存，Esc 取消；底部三个按钮可单独清除网址、清除图标、选择本地图片。

    搜索：进入页面自动聚焦，Enter 搜索；点击左侧按钮切换搜索引擎，可自定义。

    快捷键：搜索框未聚焦时，按字母键直达对应网站；Esc 聚焦 / 取消聚焦搜索框。

    图标：支持图片链接、文字、本地图片；无图标时自动获取网站图标，失败显示「无」。

    背景：右键空白处选择本地图片作为背景；可清除、显隐链接、调整文字颜色。

    数据：全部保存在浏览器 localStorage；右键空白处「导出数据 / 导入数据」可备份或在浏览器 / 设备间迁移。

    同步：「WebDAV 设置」配置自己的 WebDAV 网盘并打开开关，「立即同步」手动上传全部链接与设置到云端；不会自动同步，可用「从云端恢复」取回。
