# MyTab

我的

## 介绍

自制的浏览器起始页，自己用

+ 最初版本
+ 只有一个时间和一个搜索框

### 搜索框效果

1. 进入主页时自动聚焦
2. 聚焦时放大，出现图标，背景图放大，颜色、透明度等变化
3. 点击区域外取消聚焦，并且缩短

#### v2.0

1. 在初版基础上，增加了网站快捷链接
2. 链接可以通过右键键盘格添加到对应位置
3. 可以自定义图标，~~暂只支持链接~~，已支持选择本地图片，选好一个要刷新一次页面。图标同时设置了链接和本地文件时，优先显示本地
4. 不会后端，不能保存自定义修改
5. 用localStorage保存自定义的网址
6. 可以按键操作：
   + esc可以聚焦或取消聚焦搜索框，聚焦搜索框时enter搜索
   + 右键出现键盘格菜单后，esc菜单消失，上、下调整光标所在输入框，enter添加
   + 在右键菜单消失并且搜索框不聚焦时，按对应键盘的字母按键可以进入对应已设置的网址
7. 可以通过在右键菜单的“网址”栏输入“clear”清除对应的localStorage记录
8. 加入了联想词，可以点击前往搜索，联想词带空格不能正常搜索，只能搜索到空格前的部分
9. 右键背景可以更改背景，~~图片大小限制在2M内~~，增加选项以清除添加的背景，通过压缩图片让其能被localstorage存储，不限制一般大小的图片
10. 右键背景可以设置快捷链接的显示和隐藏
11. 添加快捷链接的hover效果，视觉体验改善

12. 添加修改字体颜色的按钮，自定义修改时间和快捷链接字母提示的字体颜色，目前支持黑白切换。
13. 克隆到本地，提交测试。2024.8.2

#### v3.0

当前分支 v3.0-dsh-20260818：基于 v2.0 的代码优化版（DeepSeek Harness 协助，2026.8）。localStorage 键位保持不变，原有自定义数据完全兼容：

1. 统一事件绑定：改用 addEventListener，修复 window.onkeydown / window.onclick 被反复覆盖导致的相互冲突
2. 修复联想词：正确域名 + URL 编码（带空格可正常搜索）+ textContent 防注入 + 输入防抖
3. 修复清除逻辑：在网址栏输入 clear 才清除记录（原代码只判断 c），并同步重置链接与图标 DOM
4. 修复图标替换：添加/更换本地图标无需刷新页面
5. 修复搜索时序：点击搜索按钮不再依赖失焦取值，搜索后保留已输入内容
6. 交互优化：空链接点击直接弹出编辑菜单；输入网址自动补全 https://
7. 代码结构：移除 HTML 内联事件，逻辑收进 IIFE，消除全局变量
8. 性能与适配：字体 font-display: swap 不阻塞首屏；搜索框/联想词响应式宽度；≤900px 小屏适配
9. 快捷键扩展：Alt+字母 直接唤出对应格子的编辑菜单
10. 搜索引擎切换：点击搜索框左侧按钮切换百度/必应/谷歌/搜狗，可自定义搜索引擎（搜索链接含 {q} 占位符），选择持久化；联想词仅百度可用
11. 文字图标：有链接无图标时自动尝试获取网站 favicon，失败则用域名首字母生成彩色文字图标；图标栏输入普通文字（非图片链接）时以文字形式展示

#### v3.1（现代化重构，2026.8）

在 v3.0 基础上完成代码现代化，并补全了「后续想法」中剩余的全部功能：

1. 代码现代化：ES6+（const/let、箭头函数、模板字符串）、event.key、语义化类名、CSS 变量、:focus-visible、prefers-reduced-motion
2. 新增「名称」栏与悬浮提示：编辑菜单可填网站名称；鼠标悬停快捷链接时浮现跟随鼠标的提示，显示名称与网址
3. 编辑菜单重构：底部新增「清除网址 / 清除图标 / 本地图片」三个按钮；右键已配置的链接时自动预填网址、名称、图标（在线链接 / 文字 / 本地图片文件名）
4. 移除 Alt+字母唤出菜单（避免与其他快捷键冲突）
5. 默认无背景图片，使用白色作为底色；清除背景回到白色；时间 / 链接文字默认黑色（适配白底）
6. 右键空白处菜单新增「使用方法」，点击展开使用说明
7. 网站图标获取失败时显示汉字「无」
8. 右键快捷链接菜单与空白处菜单 UI 优化：毛玻璃、圆角、阴影、hover 反馈；打开任一菜单时自动关闭其他浮层，避免多个菜单同时显示冲突
9. 自定义搜索引擎改为弹窗表单（替换 prompt）
10. localStorage 键位保持不变，原有自定义数据完全兼容；新增名称（81-106）与本地图标文件名（108-133）键位
